# 实验研究粗读检查

用于湿实验、材料制备、动物或细胞实验、装置实验以及以仪器测量为核心证据的论文。只展开会改变论文主张、灵感迁移或验证可行性的条件。

## 对象、变量与对照

- 实验单位是什么，样本来自哪里；样本量指独立实验单位还是重复测量？
- 自变量、因变量、控制变量和主要读出分别是什么？
- 阴性、阳性、空白、载体、标准品或现有方法对照中，哪些是解释核心结论必需的？
- 随机化、盲法、批次和平衡设计只在会影响实验解释时核对。

## 研究流程与真实时间轴

先给研究流程：

> 样本或材料准备 → 干预/制备 → 培养/反应 → 取样 → 测量 → 分析 → 结论

只有原文报告真实时点时，再给实验时间轴，包括预处理、给药或操作、孵育/反应时间、采样点、随访或终点。不要把论文叙述顺序当成实验发生顺序。

## 决定性条件与证据

- 材料或试剂规格、配比、浓度、几何尺寸、温度、压力、气氛、时间和操作顺序中，哪些控制了关键机制？
- 仪器型号、校准、测量模式、采集参数和数据处理怎样影响主要读出？
- 每个实验排除了哪个替代解释，又留下了什么解释空间？
- 主要结论依靠单一读出，还是有正交测量、剂量响应、时间响应、扰动或救援实验支持？
- 区分技术重复、独立重复和代表性图像；统计显著不自动等于效应具有实际意义。
- 作者声称机制时，证据是在直接测量机制，还是只观察到与机制一致的结果？

## 灵感来源

优先寻找：用新扰动、对照或读出增强机制判别；改变材料、尺度、边界、时点或环境使效应显现；重新连接两个成熟步骤；先用低成本代理读出筛选再用高成本方法确认；利用异常、失败条件、极端区间或反例建立新假设。

灵感卡必须说明迁移后保留的是机制、操作结构还是测量策略；只替换研究对象不构成完整灵感。

## 最小验证

1. 选择一个能代表目标情境的实验单位或条件范围。
2. 保留一个基线或阴性对照；解释阳性结果确实需要时再加入阳性对照。
3. 只改变灵感卡中的核心因素，其余关键条件保持一致。
4. 使用一个直接或足够接近机制的决定性读出，并预先写明停止标准。
5. 设置足以判断方向和实验变异的独立重复；数量根据变异与决策需求说明。
6. 控制最可能导致假阳性、假阴性或批次混淆的因素。

输出实际操作顺序和必要时点。若最小实验只能证明现象、不能证明机制，应明确它完成的是筛选而非机制验证。

## 复现清单

最小复现至少核对：样本或材料来源、关键规格与批次、制备或处理顺序、浓度/配比、环境条件、真实时点、必要对照、仪器与采集模式、原始数据处理、统计单位和目标结果。完整复现再加入所有次要条件、扩展对照、机制验证和补充实验。把论文未报告的参数与当前材料不可见的参数分开列出。
